# eICU-MPP

An LLM-based pipeline integrating ICU mortality prediction,
decision margins, and patient-specific clinical evidence synthesis
in structured clinical reports.

## Code availability

The code for the eICU-MPP pipeline will be made publicly available
in this repository upon publication of the associated manuscript.

## Data availability

This study uses the eICU Collaborative Research Database.
Access requires credentialing through PhysioNet.
Patient-level data will not be distributed through this repository.
